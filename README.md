## ୨ৎ Sobre 
O projeto surgiu como um trabalho em grupo para a disciplina de Porgramação Orientada a Objetos, onde o objetivo era desenvolver um jogo utilizando a liguagem JAVA. O grupo decidiu criar um tamagotchi, na qual o animal virtual seria um rato, podendo proporcionar uma interação divertida e envolvente para que os usuários possam realmente expressar sua criatividade ao cuidar de um ratinho. O jogo tem uma interface simples e intuitiva, apresentando as interações que pode realizar com o tamagotchi apos determinar a cor e o nome do seu bichinho.

## ୨ৎ Tecnologias
Durante o processo de desenvolvimento, utilizamos algumas ferramentas que foram fundamentais, e fizemos várias modificações e alterações no código conforme necessário, adaptando as sugestões para atender melhor às nossas necessidades. O resultado é uma experiência interativa e divertida que permite aos usuários cuidar e interagir com seu próprio Tamagotchi!
